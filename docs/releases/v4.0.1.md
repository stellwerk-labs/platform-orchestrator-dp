# Orchestrator Data Plane v4.0.1

This maintenance release updates the Go toolchain and dependencies. Deployment
queue behaviour, Runner dispatch, API contracts and the v4.0.0 database schema
remain unchanged.

## Security and compatibility

Official builds use Go 1.26.10, including the certificate verification fix for
[CVE-2026-111943](https://pkg.go.dev/vuln/GO-2026-6809). HTTP, cryptography,
compression, OpenAPI and telemetry dependencies are updated. The published
`shared/v2.2.0` SDK source is unchanged.

Normal CI checks source dependencies and the compiled server for reachable
known vulnerabilities. Release binaries retain linker symbols for this scan;
DWARF debug information remains omitted. Docker build contexts exclude direnv
and local environment state. Integration fixtures use pinned Kubernetes inputs.

## Upgrade and recovery

The coordinated application patch set is Control Plane 3.1.1, Data Plane 4.0.1,
IAM 2.5.1 and Console 1.4.1. Use verified public artifacts for the selected set.
This patch adds no database migration. Back up databases, encryption material
and configuration, and drain active Deployments before upgrading. Retain the
v4.0.0 schema and use a compatible application revision or forward repair;
database Down migrations are not a recovery procedure.

The existing Runner remains a separate artifact. This patch does not update or
clear its bundled OpenTofu dependencies, the plugin runtime or external services.
