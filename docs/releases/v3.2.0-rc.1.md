# Data Plane v3.2.0-rc.1

This release candidate adds version-aware deployment and Pin handling for Module
Version Management. It continues to use the normal Deployment and Runner path.

## What changes

- Resolve managed versions and preserve eligible effective versions during
  redeployment, subject to lifecycle, archive and Pin rules.
- Enforce exact Environment Pins and explicit permissions for Proposed use and
  restricted Defective-version exceptions.
- Preview and apply atomic bulk Pin, Unpin and Discard operations against frozen
  Environment IDs, with current scope checks and idempotent command handling.
- Preserve legacy v0 execution and exact historical rollback without inventing
  source digests or version metadata.
- Retain normal encrypted Deployment outputs and existing access checks.

## Upgrade and recovery

Use CP 3.0.0-rc.1, IAM 2.4.0-rc.1 and Runner 3.1.0-rc.1 with this candidate.
Pair publishing clients with CLI/provider 2.0.0-rc.1 and Console 1.3.0-rc.1.
Do not run an older Module writer against the upgraded contract.

Back up deployment state and key storage, drain active Deployments, and apply the
supported migrations before resuming work. Existing snapshots and opaque
identities remain valid. Recovery needs a compatible application revision and
retained external source; do not drop Module or Pin history.

Data Plane migrations 15 and 16 add Module Version artifact metadata and the
version-request digest. These are deployment metadata changes, not a new
infrastructure execution path.

External artifact digests are optional immutable claims, not proof of trusted
verification. Missing historical digests must not make legacy deployment fail.

## Go contract

The separate `shared/v2.1.0-rc.1` tag publishes additive DTO/event fields under
`github.com/stellwerk-labs/platform-orchestrator-dp/shared/v2`.
It requires Go 1.24. Consumers that do not need the new fields can keep their
compatible existing version. The application tag is not the SDK tag.

This prerelease does not update stable channels. Validate public downloads and
the matching chart before relying on the candidate as an installation set.
