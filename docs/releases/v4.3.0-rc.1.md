`seed_only=true`. The seed is a CI dependency, has no stable/latest image or
GitHub application release, and does not qualify ordinary integration. Run the
normal compatible-image integration and final stable artifact gates separately.

`If-Match` revisions and audit records. Explicit human grants in IAM control
read/write access; cookie writes require the exact Console origin. New ordinary,
external, observation, plan and destroy records return503 `system_maintenance`.

promotion continue. Reads, cancellation, Runner completion and settlement remain
available. Deferred future stages without a committed record remain new work.

without dropping deployment history before settlement. Enabling maintenance
serializes with durable acceptance. The gate applies to internal actors too;
maintenance neither stops services nor performs upgrades.

state boundaries. Busy, unavailable or incomplete state cannot authorize physical
Provider collection. Published DP shared/v3 v3.2.0 adds optional usage contracts
while preserving existing generated interfaces and named schema constants.
