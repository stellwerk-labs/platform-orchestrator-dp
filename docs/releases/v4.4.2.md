# Data Plane 4.4.2

This security patch updates the OpenTelemetry Go SDK modules
`go.opentelemetry.io/otel/sdk`, `go.opentelemetry.io/otel/sdk/log` and
`go.opentelemetry.io/otel/sdk/metric` to `1.47.0`. That version fixes
[GO-2026-6974](https://pkg.go.dev/vuln/GO-2026-6974)
([GHSA-q7gw-24fr-5p69](https://github.com/open-telemetry/opentelemetry-go/security/advisories/GHSA-q7gw-24fr-5p69)):
attribute values containing U+FFFD runes could exceed the configured attribute
value length limit.

Official builds keep Go `1.26.11`. The API, permissions, database schema and
configuration are unchanged, and this patch adds no migration.

The coordinated patch set is Control Plane 4.1.2, Data Plane 4.4.2 and IAM
2.8.2, pinned together by chart `0.12.3`. Console 1.7.0 and Runner 3.3.0 are
unchanged.
